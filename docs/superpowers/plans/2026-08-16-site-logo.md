# Site logo / brand mark Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the hybrid-2 «Д» + mini-graph brand mark as favicon and as a nav/login lockup (icon + word «Древо»).

**Architecture:** Hand-authored SVG in `web/public/` for favicon and optional static reference; a small React `BrandLockup` component with **inline** SVG for UI (palette fills, no FOUC). Wire into `AppNav` and `LoginPage`. No new npm dependencies. Web has no React Testing Library — verify with lint/build and file presence checks.

**Tech Stack:** Vite + React 19, existing CSS tokens (`--accent`, `--gold`, `--paper-deep`), Fraunces via `.brand`.

**Spec:** `docs/superpowers/specs/2026-08-16-site-logo-design.md`

## Global Constraints

- Mark concept: hybrid **2** — serif «Д» + three nodes/edges on the right
- Colors: accent `#2c5f4e`, gold `#7a6b2e`, paper-deep `#d5ddd4` / paper `#e6ebe4`
- Delivery: hand-authored SVG only — no raster, no new npm deps
- Nav / login: icon **+** word «Древо» (lockup)
- Favicon: same mark as `favicon.svg` (bolder strokes OK at 16px)
- Out of scope: full redesign, OG/apple-touch PNG, dark-mode variants, product rename
- Docs: `docs/user/overview.md` and/or short UI note; check off ROADMAP logo item
- Verify: `npm run lint` + `npm run build` in `web/`; no new dependencies
- Ask before adding any new dependencies
- Existing CSS class `.brand-mark` already styles the text brand link — **do not overload it** for the icon; use new class `brand-lockup`

`web/src/components/BrandLockup.tsx`:

```tsx
import './BrandLockup.css'

type BrandLockupProps = {
  size?: number
  withWordmark?: boolean
  className?: string
}

/** Inline hybrid-2 mark («Д» + mini family graph) + optional wordmark. */
export function BrandLockup({
  size = 28,
  withWordmark = true,
  className = '',
}: BrandLockupProps) {
  const classes = ['brand-lockup', className].filter(Boolean).join(' ')

  return (
    <span className={classes}>
      <svg
        className="brand-lockup__mark"
        width={size}
        height={size}
        viewBox="0 0 112 112"
        aria-hidden="true"
        focusable="false"
      >
        <circle cx="56" cy="56" r="52" fill="#d5ddd4" />
        <text
          x="48"
          y="72"
          textAnchor="middle"
          fontFamily="Georgia, 'Times New Roman', serif"
          fontSize="54"
          fontWeight="600"
          fill="#2c5f4e"
        >
          Д
        </text>
        <circle cx="72" cy="34" r="7" fill="#7a6b2e" />
        <circle cx="86" cy="58" r="6" fill="#2c5f4e" />
        <circle cx="74" cy="78" r="6" fill="#2c5f4e" />
        <path
          stroke="#7a6b2e"
          strokeWidth="2.5"
          strokeLinecap="round"
          fill="none"
          d="M72 41v10M78 52l6 4M72 68l2-6"
        />
      </svg>
      {withWordmark ? (
        <span className="brand-lockup__word">Древо</span>
      ) : null}
    </span>
  )
}
```

Keep geometry identical to `brand-mark.svg` (favicon may use the thicker variant only in the public favicon file).
