# Roadmap — нереализованные фичи

Список запланированных задач, чтобы ничего не потерять. Отмечайте выполненное: `[x]`.

Приоритет: сверху вниз в каждом разделе. SSO / 2FA / полный редизайн — в Later, пока нет шаринга и базового recovery.

## Now

### Инфраструктура и качество

- [x] **CI + test coverage** — GitHub Actions: lint, typecheck, test, build; отчёт coverage в CI (без блокирующего порога)
- [x] **Документация по существующему функционалу** — описание API, auth, модели дерева, импорта GEDCOM, media/S3 и веб-UI (`docs/user/`, `docs/dev/`)
- [ ] **Rate limiting / hardening auth** — защита login/register на публичном демо

### Продукт

- [x] **Экспорт дерева в `.ged`** — GEDCOM export (импорт уже есть; также как backup)
- [ ] **Логотип сайта** — бренд-марка в UI и favicon
- [ ] **Сброс пароля / recovery** — восстановление доступа до SSO/2FA
- [x] **Шаринг дерева** — invite, read-only и/или соредактор (сейчас 1 user → 1 tree)

## Next

- [ ] **Поиск по людям** — быстрый поиск в большом дереве после импорта
- [ ] **Дедуп людей** — слияние дубликатов после GEDCOM-импорта
- [ ] **Backup / восстановление** — явный сценарий бэкапа (минимум через полный GEDCOM-export)

## Later

- [ ] **SSO** — OAuth / OpenID Connect (после шаринга / мультипользовательского доступа)
- [ ] **Двухфакторная авторизация (2FA)** — TOTP поверх JWT (после password reset и hardening)
- [ ] **Редизайн** — уточнять конкретными UI-задачами (навигация, canvas, мобилка, a11y), не одним чекбоксом

## Как пользоваться

1. Берите задачи из **Now**, затем **Next**.
2. После реализации — отметьте чекбокс и при желании кратко опишите в PR.
3. Новые идеи добавляйте в конец подходящего раздела.
