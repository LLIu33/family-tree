# Обзор продукта

**Древо** — личный семейный архив: люди и семьи в графе, карта на экране, обмен доступом по ссылке, импорт и экспорт GEDCOM. После регистрации у вас своё дерево; чужие открываются только по приглашению владельца.

В интерфейсе бренд **Древо** — знак (буква «Д» и мини-граф семьи) и слово в шапке и на экране входа; тот же знак в favicon.

Веб: `http://localhost:5173` (локально). API: `http://localhost:3000`. Как поднять стек — корневой [README.md](../../README.md).

## Экраны

| Экран | Путь | Кто видит |
|-------|------|-----------|
| Вход / регистрация | `/login` | гости. Вкладки «Вход» и «Регистрация» (имя, email, пароль, необязательное название дерева) |
| Домой | `/` | после входа: имя текущего дерева, «Открыть древо», для editor/owner — «Импорт GEDCOM» |
| Карта | `/tree`, `/tree/:rootId` | холст родственников, карточка человека, аватары. Писать связи и людей могут editor и owner |
| Импорт | `/import` | в меню у editor/owner. Загрузка `.ged` и скачивание `.ged` |
| Доступ | `/access` | в меню только у **владельца**: ссылки-приглашения и участники |
| Приглашение | `/invite/:token` | принятие ссылки (нужен вход) |

Шапка (`AppNav`): Домой, Карта, Импорт (если можно писать), Доступ (если owner), селектор дерева, выход.

Защищённые страницы сначала дергают `GET /auth/me`, затем показывают контент. Без токена — на `/login`.

## Роли

| Роль | В UI | Можно |
|------|------|--------|
| Владелец (`owner`) | Доступ, импорт, карта с правками | всё в своём дереве, приглашения, удаление участников |
| Редактор (`editor`) | Импорт, карта с правками | менять людей и связи, импорт GEDCOM, не управлять доступом |
| Наблюдатель (`viewer`) | Карта без правок | смотреть дерево, скачать `.ged` через API / страницу импорта, если открыть `/import` вручную. Пункта «Импорт» в меню нет |
