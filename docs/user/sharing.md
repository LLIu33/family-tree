# Совместный доступ

Владелец делится деревом ссылкой. Редактор меняет данные; наблюдатель только смотрит. Своё дерево после регистрации остаётся у вас (`OWNS`); чужие — через `MEMBER_OF`.

Пункт **Доступ** в шапке есть только при роли владельца текущего дерева. Иначе страница пишет, что управлять доступом может только владелец.

## Создать ссылку

1. Переключитесь на нужное дерево (селектор в шапке).
2. **Доступ**.
3. Роль: «Наблюдатель» (`viewer`) или «Редактор» (`editor`). Владельца так назначить нельзя.
4. **Создать ссылку**. Срок по умолчанию — 14 дней (на API можно 1–90).
5. **Копировать** — в буфер попадает полный URL (`origin` + `/invite/<token>`).

Активные ссылки — списком, с датой окончания. **Отозвать** помечает приглашение недействительным; уже принявшие доступ не теряют.

## Принять приглашение

Путь: `/invite/:token`.

- Не вошли — редирект на `/login?returnUrl=/invite/...`, после входа/регистрации возврат на ту же ссылку.
- Вошли — клиент вызывает `POST /invites/:token/accept`, сохраняет новый JWT и открывает **Карту**.

Повторный accept, если вы уже owner или member, новую роль не перезаписывает, но переключает сессию на это дерево. Просроченный или отозванный токен — ошибка.

## Переключение дерева

В шапке — список деревьев (`GET /trees`). Выбор другого вызывает `POST /trees/:treeId/switch` и перезагружает `/`. После обычного **Входа** снова открывается **личное** дерево; к shared нужно переключиться ещё раз.

## Участники

На **Доступ** — владелец и все `MEMBER_OF`. **Удалить** снимает членство (кик). Владельца удалить нельзя.
