# Импорт и экспорт GEDCOM

Страница **Импорт** (`/import`): загрузить `.ged` в текущее дерево и скачать его обратно. В меню пункт виден editor и owner. Наблюдатель форму загрузки не видит («Импорт недоступен в режиме просмотра»), блок экспорта на странице остаётся.

Данные пишутся в **активное** дерево (селектор в шапке). Перед загрузкой проверьте, что выбрано нужное.

## Импорт

1. **Импорт**.
2. Файл `.ged` / `.gedcom`.
3. **Импортировать**.

Успех: сколько людей и семей создано. Лимит API — 20 MB. Нужны роли editor или owner.

Поддерживается бытовой GEDCOM 5.5 / 5.5.1 (люди и семьи). Фото из файла не импортируются. Разбор тегов: [../dev/gedcom.md](../dev/gedcom.md).

## Экспорт

**Скачать .ged** — файл `family-tree.ged` (дерево из JWT). Доступно viewer и выше.

В файле — люди и семьи. **Нет** аватаров и прочей media (`OBJE`). Это снимок генеалогии, не полный бэкап аккаунта (без пользователей и приглашений).

Подходит как перенос в другую программу и как черновой backup графа, пока в roadmap нет отдельного «Backup / восстановление».

После импорта откройте **Карту** — показывается компонента целиком.
